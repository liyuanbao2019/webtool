# 个人 SQL 脚本

在 SQL 工具编辑 SQL 后点击“保存”，输入脚本名称即可保存到当前登录账号的脚本库。打开已保存脚本后再次“保存”会更新原脚本；“另存为”创建独立副本，同账号不允许重名。

“我的脚本”支持按名称搜索、新标签打开、重命名、删除，以及导入 UTF-8 编码的 `.sql` 文件。打开或导入不会执行 SQL，也不会覆盖当前标签页。每个账号最多 200 个脚本，单个脚本最多 1 MB。

脚本默认持久化到 `./data/saved-sql/`，重启后仍保留。备份或迁移时包含该目录。可通过 `app.saved-sql-directory` 配置其他存储目录；相对路径以服务启动目录为基准。当前实现适用于单个应用实例，多个实例请勿同时写入同一目录。

接口 `/api/database/saved-sql` 仅使用服务端登录会话确定账号。即使关闭全局登录认证，该个人脚本功能仍要求有效登录会话。文件名使用账号的 SHA-256 摘要，脚本内容以 JSON 原文保存。
