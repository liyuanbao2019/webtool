# 数据导入（CSV / 文本文件 / Excel）

SQL 工具工具栏点击“导入数据”，或在左侧表列表右键表名选择“导入数据”（自动带入目标表）。导入分三步：

1. **文件与解析**：上传文件后自动识别编码（UTF-8 / GB18030）和分隔符。可手动调整编码、分隔符（逗号、Tab、`|`、`;`、`^`、`~`、Hive `\x01`、无分隔符或自定义多字符如 `||`）、引号（`"`、`'`、无）、首行为表头、跳过行数、去除首尾空格、忽略行尾分隔符（`a|b|c|`）。下方实时显示原始内容和解析预览，列数与表头不一致的行会标黄提示。Excel 文件（.xlsx / .xls）见下文“Excel 文件”。
2. **目标表**：先选择导入方式：
   - **导入到已有表**：选择或输入表名（支持 `SCHEMA.表名`，Oracle/达梦支持同义词），加载表结构后自动按名称匹配。每个字段可选择文件列、固定值或不导入（使用数据库默认值）。页面会提示没有数据来源的必填字段。二进制字段不支持导入。
   - **新建表并导入**：工具根据文件直接在当前数据源的默认 schema（MySQL 为当前库）中建表，无需手动映射，见下文“新建表”。
3. **执行导入**：选择出错数据的处理方式后点击“开始导入”，或先点“仅校验”检查整个文件而不写库。完成后显示**导入结果**：表名（新建 / 已有）、数据源、写入行数、错误行数、耗时、每个字段的名称、类型和来源列，新建表还会附上建表语句。可“复制摘要”（纯文本，便于上报），或“查询该表”在新标签页打开 `SELECT * FROM 表`。

## 新建表

- **表名**：默认取文件名（如 `客户 2024.csv` → `客户_2024`），与已有表重名时自动加 `_2`、`_3`。可修改；只允许字母、数字、汉字、`_`、`$`、`#`。
- **字段名**：取自表头，空格和符号替换为 `_`，重名加后缀，数字开头加 `c_`；无表头时为 `col_1`、`col_2`……
- **大小写**：Oracle / 达梦的英文名转大写、PostgreSQL 转小写，建表后不加引号也能查询；MySQL 保持原样。
- **字段类型**按数据自动识别（文件不超过 10 万行时扫描全部数据，否则扫描前 10 万行并为文本长度预留一倍余量）：

  | 数据 | 类型 |
  |---|---|
  | 整数（≤ 9 位 / 10–15 位） | 整数 / 长整数 |
  | 带小数的数字 | 小数，精度按最大位数并留 2 位整数余量 |
  | `2024-01-05`、`2024/1/5` 等 | 日期；带时间的为日期时间 |
  | 其他内容，包括以 0 开头的数字（编码、工号）和超过 15 位的数字（身份证号、银行卡号） | 文本，长度取 50/100/200/500/1000/2000/4000 中能容纳最长值的一档 |
  | 超过上限的长文本（Oracle / 达梦 1000 字，其他 4000 字） | 长文本（CLOB / TEXT / LONGTEXT / STRING） |
  | 整列为空 | 文本(100) |

  `20240105` 这类纯数字按整数处理，需要日期类型时可手动改为“日期”。识别时使用第 3 步的“视为 NULL 的值”和“日期格式”设置。
- 每个字段都可以改名、改类型、改长度/精度，或取消勾选不导入。修改后实时校验并显示将要执行的建表语句。所有字段均可为空，不建主键。
- 各数据库的类型：

  | 类型 | Oracle | 达梦 | MySQL | StarRocks | PostgreSQL |
  |---|---|---|---|---|---|
  | 文本(n) | VARCHAR2(n CHAR) | VARCHAR(n×3) | VARCHAR(n) | VARCHAR(n×3) | VARCHAR(n) |
  | 长文本 | CLOB | CLOB | LONGTEXT | STRING | TEXT |
  | 整数 / 长整数 | NUMBER(10) / NUMBER(19) | INT / BIGINT | INT / BIGINT | INT / BIGINT | INTEGER / BIGINT |
  | 小数(p,s) | NUMBER(p,s) | DECIMAL(p,s) | DECIMAL(p,s) | DECIMAL(p,s) | NUMERIC(p,s) |
  | 日期 / 日期时间 | DATE / DATE（有毫秒时 TIMESTAMP） | DATE / TIMESTAMP | DATE / DATETIME | DATE / DATETIME | DATE / TIMESTAMP |

  达梦和 StarRocks 的 VARCHAR 按字节计，按每字符 3 字节换算。MySQL 建表带 `DEFAULT CHARSET=utf8mb4`，VARCHAR 总长超过行大小限制时自动把最长的字段改为 LONGTEXT。StarRocks 建为明细模型：`DUPLICATE KEY(第一列) DISTRIBUTED BY HASH(第一列)`，副本数等使用集群默认值。

### 新建表时出错怎么办

| 阶段 | 结果 |
|---|---|
| 点击开始前（表名或字段不合法、表已存在） | 页面直接提示，不执行任何操作。 |
| 建表失败（无建表权限、名称过长、表空间不足、并发建了同名表等） | 状态为“失败”，显示数据库原始错误。未建表，也未写入数据；**不会删除任何已有表**。 |
| 建表成功，导入失败且没有写入任何数据（整体回滚、文件无数据、取消、连接中断等） | 默认**自动删除本次新建的表**，可直接修正后重新导入。可在第 3 步取消勾选“自动删除新建的表”以保留空表。 |
| 建表成功，部分数据已提交（跳过错误行、遇错停止） | 保留新表及已导入的数据；下载“未导入数据”修正后，用“导入到已有表”继续导入。 |
| 自动删除失败 | 结果中显示需要手动执行的 `DROP TABLE` 语句。 |

工具只会删除本次导入自己创建成功的表。DDL 会自动提交，因此新建表不在导入事务内；如果导入过程中服务被重启，新表可能残留，需要手动删除。`CREATE TABLE`、`DROP TABLE` 和导入本身都会分别记入 SQL 审计日志。

## 出错数据处理

每一行写库前都会先按字段类型校验：列数、数字、日期、布尔值、字符长度、非空约束。数据库拒绝的行（主键冲突、约束等）也会定位到具体行。

| 方式 | 行为 | 适用场景 |
|---|---|---|
| 整体回滚（默认） | 单个事务；任何一行出错都全部回滚，不写入任何数据。出错后继续校验剩余数据（直到错误上限），一次列出尽可能多的错误。 | 数据必须完整导入 |
| 跳过错误行 | 按批提交；出错的批次回滚后逐行重试，只跳过错误行。错误行数超过上限时停止。 | 允许部分导入，事后补录 |
| 遇错停止 | 按批提交；遇到第一条错误停止，之前的数据保留。 | 有序数据，修正后从断点继续 |

导入完成后可下载：

- **错误报告**（UTF-8 CSV）：行号、字段、错误原因、原始数据。行号是文件中的物理行号。
- **未导入数据**：保持原文件编码和格式，包含表头、错误行，以及提前停止时剩余未处理的行。修正后可直接用相同设置再次导入。

其他选项：每批行数（默认 500，最大 5000）、错误上限（默认 1000）、空值按 NULL 处理、视为 NULL 的值（默认 `NULL,\N`）、自定义日期格式（如 `dd/MM/yyyy HH:mm`，已内置 `yyyy-MM-dd [HH:mm:ss]`、`yyyy/M/d`、`yyyyMMdd` 等）、列数不一致的行判为错误。

## Excel 文件

按文件内容（而非扩展名）识别 .xlsx 和 .xls。上传后把所选工作表转换为 UTF-8 CSV，之后的预览、字段映射、新建表、出错处理与 CSV 完全相同。编码、分隔符、引号等文本选项不适用，界面上改为“工作表”选择；“首行为表头”“表头前跳过行数”“去除首尾空格”仍可用。

- **取原始值，不取显示格式**：数字导出为 `1234.5`（不带千分位、货币符号、百分号，`50%` 导出为 `0.5`），按 Excel 的 15 位有效数字处理浮点误差（`0.1+0.2` → `0.3`）；设置了日期格式的单元格导出为 `yyyy-MM-dd`，带时间的为 `yyyy-MM-dd HH:mm:ss`（有毫秒时带 `.SSS`），纯时间为 `HH:mm:ss`；支持 1904 日期系统。
- 公式取 Excel 保存的计算结果；布尔值为 `TRUE` / `FALSE`；错误值为 `#DIV/0!` 等原文。合并单元格只有左上角有值。
- **行号即 Excel 行号**：空行、单元格内换行都不会让错误报告中的行号错位。
- Excel 不保存行尾的空单元格，所以比表头短的行视为后面的单元格为空，不算列数不符；表头范围之外还有数据的行才会报错。
- 切换工作表会重新转换，并清空当前的字段映射和导入结果。
- “未导入数据”下载为 UTF-8（带 BOM）CSV，可直接用 Excel 打开修改，再作为 CSV 重新导入。
- .xlsx 流式读取，大文件内存占用低；.xls 整个读入内存（格式本身最多 65536 行）。转换在上传时完成，大文件需要稍等。
- 不支持：设置了打开密码的文件（请先取消密码保护）、Excel 95 及更早格式、.xlsb（请另存为 .xlsx）。

## 说明与限制

- 上传文件临时保存在服务器 `${java.io.tmpdir}/webtool-import/`，闲置 2 小时后自动删除，每个会话最多保留 5 个上传。上传大小受 `spring.servlet.multipart.max-file-size`（默认 500MB）限制。
- 上传、导入任务都绑定当前 HTTP 会话，其他会话无法查看或下载。同一会话同时只能运行一个导入；服务端最多并行 4 个导入任务。关闭弹窗不会停止导入，可随时取消。
- MySQL / StarRocks 使用多行 `INSERT ... VALUES (...), (...)` 提高写入速度；Oracle / 达梦 / PostgreSQL 使用 JDBC 批处理。
- StarRocks 不支持事务回滚，不能选择“整体回滚”。
- “整体回滚”会把整个文件放在一个事务中，超大文件请关注数据库 undo / binlog 容量，必要时改用“跳过错误行”或拆分文件。
- 每次导入（不含“仅校验”）都会记入 SQL 审计日志：`DATA_IMPORT INTO 表 [(NEW TABLE)] FROM '文件' strategy=... status=... committed=... errors=...`。
- 接口：`/api/database/import/{upload,sheet,preview,table-columns,infer-columns,create-ddl,start,status,cancel,errors,discard}`。`upload`、`sheet`、`start` 受限流和来源校验保护；`infer-columns`、`create-ddl` 只读不写库。
