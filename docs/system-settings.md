# 系统设置

首页管理员可见“系统设置”齿轮按钮，也可访问 `/system-settings`。页面按服务、账号、SSH、Web、应用、数据库、审计、安全、日志分类展示当前 YAML 配置的参数，支持搜索、修改、新增和删除。列表下标从 0 开始且必须连续。密码、令牌不会返回浏览器；空白保留原值，输入新值替换。

所有设置保存后需要人工重启。不会自动停止终端、SQL 或部署任务。保存前执行类型与关键参数校验、管理员账号保留检查，并检测其他管理员的并发修改。保存失败保留草稿。

完整参数快照写入 `./config/system-settings.json`，下一次启动在配置绑定前载入。原 YAML 不被修改。首次保存后，快照替代原 YAML 中受管理的参数，避免删除的账号和列表元素再次从旧配置中回退；命令行和环境变量仍优先。需要恢复原 YAML 时，停止服务后移走此快照再启动。已有快照每次写入前保留 `.bak`，可以停服后恢复。文件含凭证，应限制目录访问权限。可通过外部配置 `app.system-settings-file` 指定位置，此路径本身不在页面内编辑。

服务器清单、运行时数据源和常用网站仍在原有页面管理，其独立文件优先于 YAML 初始值；系统设置页提供相应入口，并明确标注默认值的作用。该模块不编辑独立运行的 webtool-agent 配置文件。
