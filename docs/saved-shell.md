# 个人 Shell 脚本库

SSH 终端连接页顶部增加“我的 Shell 脚本”。可按名称搜索、载入预览、重命名和删除个人脚本；无需先建立 SSH 连接即可管理。

在“执行脚本”窗口粘贴命令或导入 `.sh` / `.bms` / `.zip` 后，点击“保存脚本”并输入名称即可保存。载入已有脚本后，“保存脚本”更新原脚本；“另存为”创建独立副本。同账号不允许重名，每个账号最多 200 个脚本，单个 UTF-8 脚本内容最多 256 KB，与现有执行上限一致。

脚本按 **WebTool 平台登录账号** 隔离，与目标服务器的 SSH 账号无关，可在多台服务器间复用。载入仅填入预览，不自动执行；运行时仍使用现有 SSH 会话校验、脚本风险扫描和确认流程。执行使用独立 Bash 通道，不继承交互终端的 `su/sudo`、工作目录和环境变量。当前执行入口仍仅支持传统 SSH 模式。

默认保存在 `./data/saved-shell/`，重启后保留。可通过 `app.saved-shell-directory` 指定存储目录，备份时包含该目录。内容以 JSON 原文保存，请限制目录访问权限。单实例使用，多个实例不要同时写入同一目录。

接口为 `/api/ssh/saved-shell`，所有管理请求都从登录会话取得账号，不接受客户端指定归属；即使关闭全局认证也仍要求登录会话。列表只返回名称、ID、更新时间等元信息，载入时才请求脚本正文。前端没有定时保存，不缓存终端输出。
