# 个人接口库

“接口调测”页左侧是“我的接口”，用来保存调测过的接口，之后随时打开继续调测。接口按 **WebTool 登录账号** 隔离，每人只能看到自己保存的接口。

## 保存

- 填好方法、地址、参数、请求头和请求体后，点击请求栏上方的“保存”（或按 `Ctrl+S`）。首次保存时填写接口名称，选择文件夹（可在弹窗里直接新建），可写备注。名称默认取 URL 路径。
- 打开已保存的接口后，标题显示“文件夹 / 接口名”。修改后显示“已修改”，再点“保存”直接更新原接口。“另存为”创建一份新接口。
- “新建”清空编辑区，开始一个未保存的接口。切换接口、新建或关闭页面时，如果有未保存的修改会先提示。
- 保存的是请求本身：方法、地址、参数、请求头、请求体、备注。不保存响应结果。参数和请求头里的空白行不保存。

## 文件夹与管理

- 文件夹可以多级嵌套，最多 5 层，点击文件夹名展开或折叠。
- 鼠标移到某一行上会出现操作按钮：
  - 文件夹：新建子文件夹、重命名、移动、删除。删除时，里面的子文件夹和接口一起删除，删除前会提示数量。
  - 接口：重命名、移动、复制、删除。复制出的接口在同一文件夹，名称加“ 副本”。
- 同一文件夹中接口名称不能重复，同一位置文件夹名称不能重复，不区分大小写。
- 搜索框按名称、地址、方法、备注查找。命中的接口会连同所在文件夹一起显示；文件夹名命中时显示该文件夹的全部内容。
- 左上角按钮可以收起或展开接口库，收起状态和文件夹的折叠状态记在当前浏览器中。

## 限制

| 项目 | 上限 |
|---|---|
| 每个账号的接口数 | 500 |
| 每个账号的文件夹数 | 200 |
| 文件夹层级 | 5 层 |
| 接口名称 / 文件夹名称 | 100 / 50 个字符 |
| 单个接口（地址、参数、请求头、请求体、备注合计） | 1 MB |
| 请求方法 | GET、POST、PUT、DELETE、PATCH、HEAD、OPTIONS |

## 存储与安全

- 默认保存在 `./data/saved-api/`，每个账号一个 JSON 文件，文件名是账号的 SHA-256 摘要。可通过 `app.saved-api-directory` 指定目录，备份时包含该目录。每次先写完新文件再替换旧文件；文件损坏时报错并保留原文件，不会覆盖。
- **请求头和请求体按原文保存**，包括 `Authorization`、Cookie、令牌等。只有本人账号能通过接口读取，但服务器管理员可以看到文件内容。请限制目录访问权限，不要保存生产环境的长期密码。
- 接口 `/api/test/saved-api` 只从登录会话取得账号，不接受客户端指定。即使关闭全局登录认证，也仍要求有效的登录会话。写操作受 CSRF 校验。列表只返回名称、方法、地址等概要，打开时才读取完整内容。
- 适用于单实例部署，多个实例不要同时写入同一目录。

接口：`GET /api/test/saved-api`；`/requests` 的 `POST`（新建）、`GET|PUT|DELETE /{id}`、`POST /{id}/rename|move|copy`；`/folders` 的 `POST`（新建）、`POST /{id}/rename|move`、`DELETE /{id}`。
